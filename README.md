# FitBite - Calorie & Macro Tracker

A clean, responsive, and private daily calorie and macronutrient tracker built with vanilla HTML, CSS, and JavaScript.

## Features
- **Zero Backend / Serverless**: 100% client-side running directly in the browser.
- **Persistent Data**: All food logs, macro targets, and daily progress are saved in `localStorage`.
- **Macro & Caloric Breakdown**: Tracks Calories, Protein, Carbohydrates, and Fats with visual progress bars and dynamic energy distribution.
- **Meal Categories**: Organized tracking for Breakfast, Lunch, Dinner, and Snacks.
- **Quick-Add Presets**: 1-click presets for common foods (boiled eggs, oatmeal, chicken breast, rice, etc.).
- **Date Navigation**: Jump to any day, view past records, or pick a date from the calendar.
- **Import / Export**: Backup or restore your data via JSON files.
- **Pure Vanilla**: Zero CSS frameworks, zero CSS variables, zero runtime dependencies.

## Getting Started
Simply clone the repository and open `index.html` in any web browser:
```bash
git clone <repository-url>
cd <repository-directory>
# Open index.html in your browser
```
